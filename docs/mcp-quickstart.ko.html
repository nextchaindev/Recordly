Recordly MCP 연동 빠른 시작 (Windows)

AI 에이전트(Claude Code, Cursor 등)가 Recordly로 특정 앱 창만 녹화하고 스크린샷을 찍게 하는 설정입니다. Node.js 설치가 필요 없습니다. 설치된 Recordly.exe가 MCP 서버를 직접 실행합니다.

1. 설치

  1. Recordly-windows-x64.exe를 실행합니다.
  2. 설치 마법사에서 "현재 사용자만"을 고릅니다. 그러면 C:\Users\<사용자>\AppData\Local\Programs\Recordly에 설치되고, 같이 받은 설정 파일을 그대로 쓸 수 있습니다.
"모든 사용자"(관리자 권한)로 설치하면 C:\Program Files\Recordly에 들어갑니다. 이 경우 설정 파일의 경로 두 곳을 C:/Program Files/Recordly/Recordly.exe 와 C:/Program Files/Recordly/resources/mcp/recordly-mcp-server.mjs 로 바꿔야 합니다.

2. MCP 등록

가장 쉬운 방법: Claude 데스크톱 앱에 확장 프로그램으로 설치

  1. 같이 받은 Recordly-MCP.mcpb 파일을 더블클릭합니다. Claude 앱이 열리면서 "확장 프로그램 설치" 창이 뜨면 설치를 누릅니다.
  2. 더블클릭으로 안 열리면 Claude 앱 → 설정 → 확장 프로그램(Extensions) → 고급 설정 → 확장 프로그램 설치… 에서 그 파일을 고릅니다.
  3. 설정 항목 "Recordly executable"은 비워 둡니다. 기본 위치에 설치된 Recordly는 자동으로 찾습니다.

Node.js 설치, JSON 편집, 명령어 입력이 전혀 필요 없습니다. Claude 앱이 내장 실행기로 서버를 돌립니다. 설치가 끝나면 새 채팅에서 바로 recordly_* 도구가 보입니다.

확장 프로그램은 Claude 앱의 채팅에서 쓰입니다. Claude 앱 안의 Code 탭(코딩 에이전트)이나 Cursor에서 쓰려면 아래 파일 복사 방법을 씁니다.

Claude 앱 (Code 탭)

  1. 같이 받은 claude-code.mcp.json을 작업 폴더(예: 바탕화면의 AI캡처)에 복사합니다.
  2. 파일 이름을 .mcp.json으로 바꿉니다. (탐색기에서 이름 바꾸기 → .mcp.json 입력 → Enter. "확장명을 바꾸시겠습니까?" 하면 예.)
  3. Claude 앱의 Code 탭에서 그 폴더를 엽니다. "이 프로젝트의 MCP 서버를 사용할까요?" 하고 물어보면 허용을 누릅니다.

이 파일은 %LOCALAPPDATA% 변수를 쓰므로 사용자 이름을 고칠 필요가 없습니다.

Cursor

  1. Cursor에서 Ctrl+Shift+J → MCP → Add new MCP server. mcp.json 파일이 열립니다.
  2. 같이 받은 cursor-mcp.json 내용을 붙여넣고, <사용자이름> 두 곳을 본인 Windows 계정 이름으로 바꿔 저장합니다.

Claude 데스크톱 채팅 앱

설정 → 개발자 → 구성 편집을 누르면 claude_desktop_config.json이 열립니다. cursor-mcp.json 내용을 붙여넣고 저장한 뒤 앱을 다시 시작합니다.

터미널이 편하면 (Claude Code)

claude mcp add recordly -e ELECTRON_RUN_AS_NODE=1 -- "%LOCALAPPDATA%\Programs\Recordly\Recordly.exe" "%LOCALAPPDATA%\Programs\Recordly\resources\mcp\recordly-mcp-server.mjs"

3. 처음 한 번: Recordly를 MCP로 켜기

  1. Recordly가 이미 켜져 있으면 종료합니다. Windows에서는 트레이 아이콘이 없습니다. 화면에 떠 있는 Recordly 바(HUD) 오른쪽 끝의 X를 누르거나, 작업 표시줄의 Recordly 아이콘을 우클릭 → 창 닫기를 누르면 됩니다.
  2. 에이전트에게 "recordly_launch 실행해 줘"라고 말합니다.

제어 서버가 켜진 상태로 Recordly가 실행되고 설정에 저장됩니다. 이후에는 시작 메뉴로 평소처럼 실행해도 MCP가 붙습니다.

4. 에이전트에게 시키는 방법

Recordly로 Cursor 창만 녹화해 줘. 마이크는 끄고, 카운트다운 없이.
텍스트는 붙여넣지 말고 직접 타이핑하듯 입력하고, 답을 기다리는 동안 마우스는 화면 구석으로 옮겨 줘.
녹화가 끝나면 D:\AI캡처\cursor\90_recording_agent_flow.mp4 로 1280x720, 앱 화면만 나오게 내보내 줘.
그리고 Cursor 창 스크린샷을 D:\AI캡처\cursor\01_editor_home.png 로 찍어 줘.

에이전트가 내부적으로 쓰는 순서

순서도구하는 일
1recordly_arrange_window name="Cursor"창을 1280x760(내용 720 + 제목표시줄 40)으로 화면 가운데에 배치
2recordly_start_recording source={"name":"Cursor","type":"window"} microphoneEnabled=false countdownSeconds=0그 창만 녹화 시작 (바탕화면·작업표시줄 제외)
3(컴퓨터 유즈 / 브라우저 도구)대상 앱 조작. 텍스트는 한 글자씩 타이핑, 대기 중엔 마우스를 빈 곳으로
4recordly_stop_recording녹화 정지 (편집기가 열림)
5recordly_export_recording outputPath="D:\AI캡처\cursor\90_recording_agent_flow.mp4"Recordly 내보내기: 제목표시줄 제거, 여백 0, 검은 배경, 16:9, 마우스 커서 포함 → 정확히 1280x720
6recordly_capture_screenshot name="Cursor" outputPath="D:\AI캡처\cursor\01_editor_home.png"창 단독 스크린샷
왜 창을 먼저 가운데로 옮기나요? 창 녹화는 모니터 화면을 창 영역만큼 잘라 찍기 때문에, 화면 가장자리에 그려지는 "클로드가 컴퓨터를 사용 중" 테두리가 창 위에 겹치면 그대로 찍힙니다. 가운데 1280x760이면 그 테두리 밖이라 들어가지 않습니다.
왜 원본 mp4가 아니라 내보내기를 쓰나요? 원본 캡처에는 마우스 커서가 없고(좌표만 따로 기록), Recordly 내보내기가 커서를 부드럽게 다시 그립니다.
같은 제목의 창이 여러 개인 앱(예: ChatGPT 데스크톱 앱은 마스코트 오버레이 창 제목도 "ChatGPT")은 실제 앱 창을 자동으로 고르지만, 확실히 하려면 recordly_list_sources에서 본 id로 지정하라고 하면 됩니다.

증상해결
